# SniperPitchLimiter

Экспериментальный плагин CounterStrikeSharp для Linux-серверов CS2: ограничивает наклон головы вниз через параметр прицеливания AnimGraph 2. Разрабатывался для HvH-сервера, где сильный наклон со снайперским оружием мешал видеть голову на расстоянии.

## Что делает

- Ограничивает `m_flAimPitchAngle` в контроллере AG2 после штатного расчёта углов.
- По умолчанию применяется к AWP, SSG 08, SCAR-20 и G3SG1.
- Не записывает углы камеры или выстрела (`V_angle`, `EyeAngles`) и не использует `Teleport`.
- Позволяет менять лимит во время игры без перезапуска.
- Проверяет версию серверной библиотеки и отключает коррекцию при несовпадении.

Изменение позы подтверждено наблюдением со стороны другого игрока на тестовом сервере. Собственное третье лицо чита может показывать локальную позу. Совпадение хитбоксов, работа lag compensation и влияние на регистрацию попаданий отдельно не подтверждены; плагин не следует представлять как проверенное исправление хитрегистрации.

## Совместимость

- Linux x86-64, Metamod:Source и CounterStrikeSharp API **379**.
- Для сборки исходников нужен .NET SDK **10**.
- Версия 0.3.0 привязана к конкретной проверенной сборке `game/csgo/bin/linuxsteamrt64/libserver.so`:

```text
SHA256: 1F3FE3A814EAC5909B59B03D8464BC4808ADB9AD21F9BA1C6349F56F1664FA6D
```

На другой сборке CS2 коррекция автоматически не включится. После обновления игры требуется заново проверить функцию, сигнатуру, структуру параметра и смещение. Простая замена хеша без проверки не обеспечивает совместимость. Windows не поддерживается.

## Установка

1. Скачайте `SniperPitchLimiter-0.3.0-linux.zip` из Releases.
2. Распакуйте папку `addons` в `game/csgo/` сервера, объединив каталоги.
3. Если плагин уже установлен, сохраните свой JSON перед заменой. Конфиг из архива включает коррекцию с лимитом **70°**.
4. Загрузите плагин из консоли сервера:

```text
css_plugins load SniperPitchLimiter
css_pitch_status
```

При обновлении DLL включённая функция hot reload CounterStrikeSharp может перезагрузить плагин автоматически. Проверяйте статус после загрузки: `enabled=True`, `hooked=True`, `faulted=False`. Установка хука происходит на первом тике; на пустом сервере в состоянии hibernation он может ожидать подключения игрока.

## Конфигурация

Путь относительно `game/csgo/`:

```text
addons/counterstrikesharp/configs/plugins/SniperPitchLimiter/SniperPitchLimiter.json
```

```json
{
  "Enabled": true,
  "MaxDownPitch": 70,
  "SnipersOnly": true,
  "GraphDownSign": 1,
  "ConfigVersion": 1
}
```

| Параметр | Значение |
| --- | --- |
| `Enabled` | Включает коррекцию при загрузке конфига. |
| `MaxDownPitch` | Допустимый наклон вниз, от 0 до 89°. Меньшее значение сильнее поднимает голову; большее разрешает опустить её ниже. Это параметр прицеливания графа, а не точный угол кости головы. |
| `SnipersOnly` | Ограничивает действие четырьмя снайперскими винтовками. При `false` действует независимо от оружия. |
| `GraphDownSign` | Знак направления вниз в параметре графа. Для проверенной сборки — `1`; без исследования не менять. |

В исходниках безопасные значения при отсутствии конфига: `Enabled=false`, `MaxDownPitch=15`. В архиве поставляется отдельный конфиг с `Enabled=true`, `MaxDownPitch=70`.

## Команды

Доступны из серверной консоли/RCON или игроку с правом `@css/root`:

```text
css_pitch_status
css_pitch_enable 0
css_pitch_enable 1
css_pitch_limit 70
css_pitch_sign 1
```

`css_pitch_limit` применяется на следующем вызове расчёта прицеливания AG2, перезапуск не нужен. Команды меняют настройки только на текущую сессию. Для сохранения после перезапуска укажите те же значения в JSON; одна правка JSON сама по себе не гарантирует немедленного изменения активного лимита.

Статус показывает исходное и изменённое значение параметра, количество коррекций и возраст образца `ageMs`. Старый образец не подтверждает, что игрок сейчас держит снайперку или находится в той же позе.

## Сборка

```sh
dotnet build src/SniperPitchLimiter/SniperPitchLimiter.csproj -c Release
```

Файлы для установки: `SniperPitchLimiter.dll` и `SniperPitchLimiter.deps.json` из `src/SniperPitchLimiter/bin/Release/net10.0/`. Конфиг-пример находится в `config/`.

## Отключение

```text
css_pitch_enable 0
```

И установите `Enabled=false` в JSON, чтобы коррекция оставалась выключенной после перезапуска. Плагин не возвращает AnimGraph 1 — он ограничивает один параметр AG2.
